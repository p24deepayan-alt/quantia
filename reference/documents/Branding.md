# Quantia – Branding Document

## 1. Brand Identity

**Name**: Quantia  
**Tagline**: “Statistics, no code. Power, no cloud.”  
**Core values**: Precision, Clarity, Offline Freedom, Accessibility.

## 2. Colour Palette

| Usage | Colour Name | Hex | RGB | Example |
|-------|-------------|-----|-----|---------|
| Primary (brand) | **Deep Indigo** | `#2C3E8F` | (44,62,143) | Logo, primary buttons |
| Secondary (accents) | **Teal Accent** | `#009688` | (0,150,104) | Hover states, links |
| Success | **Seafoam Green** | `#26A69A` | (38,166,154) | Positive results, “Run” |
| Warning | **Amber** | `#FFC107` | (255,193,7) | Assumption violations |
| Error | **Coral Red** | `#EF5350` | (239,83,80) | Errors, missing data alerts |
| Neutral (text) | **Slate Dark** | `#2D3E50` | (45,62,80) | Main text |
| Neutral (light text) | **Cloud** | `#F5F7FA` | (245,247,250) | Dark mode background |
| Background (light theme) | **Off‑White** | `#FAFBFD` | (250,251,253) | Main window bg |
| Background (dark theme) | **Near Black** | `#1E1E2E` | (30,30,46) | Dark theme bg |

**Themes**: Quantia offers three built‑in themes:
- **Quantia Light** (default): Off‑white background, Deep Indigo accents.
- **Quantia Dark**: Near black background, Teal Accent for highlights.
- **High Contrast**: Black background, yellow/white text, Coral Red buttons (accessible).

## 3. Typography

- **Primary font (UI)**: **Inter** (sans‑serif, modern, highly readable). Fallback: Segoe UI, Helvetica, Arial.
- **Monospace (code)**: **Fira Code** (with ligatures). Fallback: Consolas, Monaco, Courier New.
- **Headings**: Semi‑bold Inter, letter spacing 0.
- **Body**: Regular Inter, 13pt (1.5 line height).

## 4. Logo & Iconography

- **Logo**: A stylised “Q” made of two overlapping distributions (normal curves) forming the letter. Colour: Deep Indigo with a Teal dot at the bottom right.
- **App icon**: The “Q” logo on a clean background (rounded square, macOS/iOS style; Windows: circular).
- **Toolbar icons**: From the **Feather** icon set (simple, outline style, colour‑coded by function).
- **Data icons**: CSV, Excel, SPSS, etc. use flat mini‑logos.

## 5. UI Component Styling

- **Buttons**: Rounded corners (4px), flat with subtle shadow on hover. Primary button = Deep Indigo background, white text.
- **Input fields**: Light grey border, 2px corner radius. Focus state = Teal Accent border.
- **Tables**: Zebra striping (very light grey/white). Selected row = Deep Indigo at 20% opacity.
- **Panels**: 1px light grey border, drop shadow (depth 1).
- **Dialogs**: Semi‑transparent backdrop (light theme: 10% black overlay; dark theme: 40% black overlay), rounded corners (8px).

## 6. Tone of Voice (UI text and tooltips)

- **Plain‑language explanations**: Friendly but professional. e.g., “The Shapiro‑Wilk test says your data is **not normally distributed** (p = 0.02). You may want to use a non‑parametric test.”
- **Buttons**: Action‑oriented (“Run analysis”, “Check assumptions”, “Generate code”).
- **Error messages**: Helpful, not technical. “Could not import file: missing column ‘ID’. Please check the file format.”

## 7. Splash Screen & About Dialog

- **Splash screen** (on startup): Deep Indigo background, white “Q” logo, tagline “Loading Quantia…”, progress bar in Teal.
- **About dialog**: Logo, version, license (e.g., “Free for academic use” or commercial), list of main libraries (pandas, Qt, etc.), copyright.

## 8. Consistent Spacing

- **Grid system**: 8px base unit.
- **Margins**: 16px around main containers.
- **Padding inside dialogs**: 12px.
- **Line height**: 1.5 for text, 1.2 for headings.
